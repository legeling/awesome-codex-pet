# Web

This folder contains a Vercel-ready Next.js gallery for Awesome Codex Pet.

## Local development

```bash
cd web
npm install
npm run dev
```

## Build

```bash
cd web
npm run build
```

## Vercel

- Framework: Next.js
- Root Directory: `web`
- Build Command: `npm run build`
- Output Directory: default Next.js output
