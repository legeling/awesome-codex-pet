# Contributing

[简体中文](./docs/zh-CN/CONTRIBUTING.md) | English

The detailed contribution guide lives in the language-specific docs:

- English: [docs/en/CONTRIBUTING.md](./docs/en/CONTRIBUTING.md)
- 简体中文: [docs/zh-CN/CONTRIBUTING.md](./docs/zh-CN/CONTRIBUTING.md)

Quick checklist:

- Use `pets/<pet-slug>--<author-slug>/`
- Include `pet.json` and `spritesheet.webp`
- Keep `pet.json` `id` equal to the folder name
- Fill in `submission.json`
- Do not place previews, QA files, references, or README files inside the pet folder
- Run `npm run validate` and `npm run lint`
